# 01 · 现状分析与积分系统设计原则

## 一、现状事实（2024，三年级）

| # | 来源 | 事实 |
|---|------|------|
| 1 | 数学老师 | 上课眼神空洞，感觉不在听 |
| 2 | 数学老师 | 课后作业有抄袭现象 |
| 3 | 数学老师 | 课后练习质量很不好 |
| 4 | 家长观察 | 体能课注意力也不集中 |
| 5 | 家长感受 | 孩子表现得"是为了家长"在学习和锻炼 |

## 二、事实背后的因果链

这些事实很可能不是四个孤立的问题，而是一条链：

```
上课走神没听懂 → 作业不会做 → 抄袭应付 → 练习质量差 → 更听不懂下节课 → 更走神
```

关键判断：

1. **抄袭更可能是"结果"而不是"品德问题"**——他用抄袭来掩盖"不会"，说明他知道错但不能面对"我不会"这件事。
2. **注意力不集中是跨场景的**（数学课 + 体能课），说明不是讨厌数学，而是普遍的专注力和投入度问题。需要观察：睡眠是否充足、放学后是否疲惫、屏幕时间、任务难度是否超出能力。
3. **最核心的问题是第 5 条**：学习所有权在家长手里。孩子把自己定位成"执行者"，积分系统如果设计不当（变成监控+惩罚工具），会**加重**"为你学"的心态，适得其反。

## 三、积分系统的设计原则（防坑清单）

1. **奖过程，不奖结果**：积分只给"行为"（独立完成、讲题、订正、专注时段），不给分数和排名。他现在的结果是达不到的，奖结果只会带来挫败。
2. **短反馈周期**：8~9 岁孩子需要即时反馈。积分日结，奖励周兑，最长不超过月。
3. **诚实安全条款**：独立做错不扣分；主动说"这题我不会"反而加分。**降低抄袭的动机**，而不是抓到重罚。
4. **孩子参与立法**：规则用家庭会议的形式和他一起定，他自己提的奖励愿望权重更高。参与感 = 所有权。
5. **克制扣分**：本系统是"赚分系统"不是"监控系统"。负面行为最多让当日相关项归零，避免大量负分。
6. **家长也被约束**：写入系统里的承诺必须兑现；每天有固定的"只听不批评"讲题时间。孩子的积分记录家长不能随意改。
7. **奖励包含"自主特权"**：如"决定周末一顿饭吃什么""指定一次全家活动"，自主感本身就是最好的奖励，逐步替代物质奖励。

## 四、可观测指标的转化

老师看到的"上课走神"家长观测不到，需要转成家庭可观测的代理指标：

| 现状问题 | 家庭可观测指标 |
|---|---|
| 上课走神 | 每天能否讲出"今天数学学了什么"（复述/讲题） |
| 作业抄袭 | 独立完成作业（不问、不查、限时）；错题能否讲清思路 |
| 练习质量差 | 计算正确率的**周趋势**（和自己比，不和别人比） |
| 注意力不集中 | 番茄钟专注块（20min/块）；体能课教练反馈 |

## 五、积分规则草案（v0，待和孩子一起修订）

### 每日项（日结）

| 行为 | 分值 |
|---|---|
| 独立完成学校作业（不问不抄） | +2 |
| 每完成一个 20 分钟番茄钟（上限 3 个） | +1 |
| 给家长讲明白今天学的一个知识点 | +3 |
| 错题订正 + 讲出错因 | +2 |
| 主动说"这题我不会/我抄了" | +1（诚实奖励） |
| 抄袭且未主动承认 | 该项 0 分 + 重做（不额外扣分） |

### 周项（周日晚结算）

| 行为 | 分值 |
|---|---|
| 本周作业全部独立完成 | +5 |
| 计算正确率高于上周 | +3 |
| 体能课投入度（教练反馈/自评） | +2 |
| 家庭会议提出被采纳的建议 | +1 |

### 兑换表（示例，价格和孩子一起商量）

| 价格 | 奖励 |
|---|---|
| 15 分 | 30 分钟游戏/动画时间 |
| 30 分 | 决定周末一顿饭吃什么 |
| 80 分 | 一次电影/公园/球赛活动 |
| 200 分 | 大目标：乐高/露营/主题乐园 |
