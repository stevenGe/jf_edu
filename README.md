# 🏡 积分小屋 —— 家庭学习积分系统

给三年级孩子的学习积分系统：**孩子自己打卡赚分，家长晚上几分钟确认，每一分都有流水可查。**

- 🧒 孩子端：今日任务打卡、看余额、看自己的每一分
- 👨‍👩‍👧 家长端：确认打卡、手动记账、流水冲正、规则调整
- 📖 设计思想：奖过程不奖结果；主动承认"不会"反而加分；积分只能赚和冲正，不能悄悄改

设计文档见 `docs/`：

- `docs/01-现状分析与积分设计原则.md` —— 业务背景与积分规则的设计逻辑
- `docs/02-技术方案与产品功能设计.md` —— 技术选型与里程碑

## 一、快速开始（本机试用）

需要 Python 3.10+。

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e .
python -m app.init_db              # 初始化数据库，会打印初始账号密码
uvicorn app.main:app --reload --port 8000
```

> 网络慢可以用国内镜像：`pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple`
>
> 初始 PIN 和密码是随机生成的，打印在 `init_db` 的输出里。
> 也可以初始化时直接指定：
> `CHILD_NAME=小明 CHILD_PIN=1234 PARENT_NAME=爸爸 PARENT_PASSWORD=yourpass python -m app.init_db`

浏览器打开 `http://127.0.0.1:8000`。手机连同一 WiFi 后访问 `http://电脑IP:8000`，建议加到主屏当 App 用。

## 二、第一次启动的 5 分钟清单

1. `python -m app.init_db`，记下打印的孩子 PIN 和家长密码
2. 家长登录 → 【设置】→ 修改自己的密码，把孩子的 PIN 改成孩子自己好记的 4 位数字
3. 【规则】页：**和孩子一起**过一遍每条规则（这就是第一次家庭会议 🤝），按孩子的意见调整分值
4. 让孩子用手机输 PIN 进去，随便打卡一项试试
5. 家长在【待确认】里点确认，让孩子亲眼看到 ⭐ 变多——第一次正反馈很重要

## 三、日常怎么用

### 孩子端（放学后，做一项勾一项）

| 页面 | 用途 |
|---|---|
| 📋 今日 | 每日任务打卡。大部分打卡后显示"⏳ 待确认"，等家长确认后入账 |
| ⏰ 番茄钟 / 💬 主动说不会 | 这两项**打卡立即入账**（即时反馈是特意设计的） |
| 📅 本周任务 | 每周一次，如"本周作业全部独立完成" |
| 📒 记录 | 自己赚过的每一分，培养"这是我的积分"的感觉 |

### 家长端（每晚约 3~5 分钟）

1. 打开【待确认】，逐条确认 ✓ 或驳回（孩子都在旁边时效果最好，当场给反馈）
2. 有临时事件（帮忙做家务、忘带作业等）→ 【记账】手动加减分，**备注必填**
3. 周日晚上：确认本周任务三项（全部独立完成 / 正确率提升 / 体能课投入）

### 每周节奏建议

- **周五前后**：和数学老师做每周一次的简短沟通（课堂专注 / 作业独立 / 练习质量）
- **周日晚**：家庭会议——结算本周积分，听孩子提下周的奖励愿望和规则修改建议

## 四、常见场景怎么办

| 场景 | 操作 |
|---|---|
| 孩子忘了打卡 | 家长【记账】页补录，备注写清楚即可 |
| 记错分了 | 【流水】页点"冲正"，自动追加一条等额反向记录。**不要直接改数据库** |
| 孩子主动承认"我抄了作业" | 依然给他打卡"主动说我抄了"**加分**，不当场批评——降低抄袭动机是本系统的核心设计 |
| 孩子觉得某条规则不公平 | 家庭会议上商量，【规则】页改分值/次数，共同立法 |
| 想加一次性任务（如帮忙洗碗） | 【记账】页自定义分值 + 备注 |
| 想下线某个任务 | 【规则】页取消勾选"上架"（历史流水不受影响） |

## 五、积分规则（种子数据）

| 行为 | 分值 | 说明 |
|---|---|---|
| 独立完成学校作业 | +2 | 家长确认 |
| 专注番茄钟（20 分钟） | +1 ×3/日 | 打卡即入账 |
| 给家长讲一道今天学的题 | +3 | 家长确认 |
| 错题订正并讲出错因 | +2 | 家长确认 |
| 主动说"我不会 / 我抄了" | +1 | 打卡即入账（诚实条款） |
| 本周作业全部独立完成 | +5/周 | 家长确认 |
| 计算正确率超过上周 | +3/周 | 家长确认 |
| 体能课认真投入 | +2/周 | 家长确认 |
| 家庭会议好建议被采纳 | +1/周 | 家长确认 |

> 兑换商店是 M2 功能（未实现）。当前阶段可以先用纸质/口头约定兑换，比如 15 分 = 30 分钟游戏时间。

## 六、部署到云服务器（Linux）

### 1. 安装并初始化

```bash
git clone <你的仓库> /opt/jfedu && cd /opt/jfedu
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/python -m app.init_db
```

### 2. systemd 服务

`/etc/systemd/system/jfedu.service`：

```ini
[Unit]
Description=JF Edu Points
After=network.target

[Service]
WorkingDirectory=/opt/jfedu
ExecStart=/opt/jfedu/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8300
Restart=always
User=www-data
Group=www-data

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now jfedu
```

### 3. 反向代理（强烈建议 HTTPS）

Caddy 示例（自动申请证书）：

```
points.example.com {
    reverse_proxy 127.0.0.1:8300
}
```

> 部署到公网后，务必确认已修改初始 PIN 和密码。

### 4. 数据备份（cron）

```cron
30 3 * * * sqlite3 /opt/jfedu/data/jf_edu.db ".backup /opt/jfedu/backup/jf_$(date +\%F).db"
```

## 八、设计要点（为什么这样做）

- **流水不可删**：家长录错只能"冲正"（追加等额反向记录）——对孩子的信任比数据整洁重要
- **余额实时汇总**：不单独存余额字段，永不对不上账
- **诚实安全条款**：主动承认不会/抄袭加分，从源头降低抄袭动机（针对"作业抄袭"现状）
- **克制扣分**：这是赚分系统，不是监控系统（针对"为家长而学"的现状）
- **两段式打卡**：孩子自己勾、家长确认——打卡动作本身就是所有权练习

完整分析见 `docs/01`。

## 九、技术栈

FastAPI + Jinja2（服务端渲染）+ SQLModel + SQLite(WAL)。纯 Python，无前端构建链，无外部 CDN 依赖。

AI 编程助手参与本项目时，请先阅读 `AGENTS.md` 中的约定。
